Privacy Policy

File Explorer

Last updated: November 19, 2026

1. Introduction

File Explorer is an Android file management application developed by EpicKohus. This Privacy Policy explains how the application accesses and handles information.

2. File Access and Storage

File Explorer requests access to device storage to provide file browsing, organization, copying, moving, renaming, deletion, compression and extraction.

Files are processed locally on the user's device unless the user explicitly initiates a sharing or network transfer operation.

3. Camera and QR Codes

The application may use the device camera for document scanning and QR code scanning. Camera access is used for these functions and requires the user's permission.

4. Network and SMB

File Explorer supports connections to SMB network shares. Network connections and file transfers are initiated by the user.

Files may be transferred to network destinations selected by the user.

5. Sharing Files

Users may share files through compatible applications installed on their devices. Shared files are handled by the selected third-party application according to its own privacy policy.

6. Donations

File Explorer may provide optional donation links to external services such as Ko-fi, as well as a cryptocurrency wallet address or QR code. Donations are voluntary and are not required to use the application.

Transactions made through external services or blockchain networks are subject to their respective terms and privacy practices.

7. Data Collection

The developer does not intentionally collect users' personal files or their contents through the application's file management features. The application does not require users to create an account.

8. Data Security

Users control which files they manage, share, delete or transfer. The application uses Android permissions and platform mechanisms to access device resources.

9. Children's Privacy

File Explorer is a general-purpose utility and is not specifically designed for children.

10. Changes to This Policy

This Privacy Policy may be updated when application functionality or data practices change. Updates will be published on this page.
